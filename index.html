A股复盘｜2026-07-27

市场整体

A股最近一个已收盘交易日为2026-07-27。三大指数集体反弹：上证指数涨1.15%报3858.25点，深证成指涨2.72%报14148.73点，创业板指涨3.16%报3590.79点。两市成交额约2.08万亿元，较上一交易日明显放量；全市场近5200只个股上涨。上周五的缩量杀跌没有继续扩散，反而被长鑫科技上市、硬科技情绪回流、医药和消费电子扩散共同扭转。今天是典型的“放量普涨 + 题材扩散”，不是单纯权重护盘。

市场情绪

情绪明显修复。全市场超百股涨停，跌停和大跌主要集中在油气、部分防御和个别高位兑现方向，亏钱效应明显收敛。长鑫科技上市首日涨465.82%、成交额超1400亿元，成为全市场流动性锚点，直接抬高硬科技风险偏好。连板层面，立新能源走出8天7板，爱丽家居、五洲医疗等延续晋级，说明短线接力从上周五防守状态切换到修复状态。但要注意，强度来自“新股虹吸 + 题材共振”，不是所有方向都具备连续加速条件。

涨停结构

涨停结构从上周五的局部抱团扩散到多题材共振。首板数量大幅增加，脑机接口、PCB、PET铜箔、MLCC、创新药、电池链、机器人均出现涨停或大涨个股。三板以上仍由立新能源、爱丽家居、五洲医疗等少数高标承担情绪高度。结构上，首板多、板块广，说明资金试错意愿恢复；但真正能否演化为主线，要看明天是否出现二板扩散和核心容量股继续放量承接。

主线题材

真主线候选是“硬科技产业链”。长鑫科技上市带动半导体、存储、PCB、MLCC、PET铜箔等方向情绪修复，长鑫科技、兆易创新、中际旭创、宁德时代等成交靠前，说明资金愿意重新给科技成长定价。脑机接口是当日最强短线热点，爱朋医疗、创新医疗、南京熊猫等涨停或大涨，强度高但持续性要看产业催化能否跟上。创新药、高压氧舱、医疗器械属于低位修复和消息催化共振。电力、机器人、电池链是轮动补涨。油气、保险、煤炭相对弱，体现资金从防御切回进攻。

热门个股

容量核心：长鑫科技上市首日涨465.82%、成交约1411.87亿元，是全天最大流动性事件；兆易创新、中际旭创、宁德时代成交靠前，反映科技与成长权重回暖。情绪核心：立新能源8天7板，爱丽家居、五洲医疗等延续连板，是短线情绪温度计。高弹性个股：爱朋医疗、倍益康、成都华微、芯碁微装、方邦股份等分别对应脑机接口、医疗器械、PCB/PET铜箔。风险反馈：中曼石油跌停，油气、保险、煤炭弱于市场，说明防御和资源方向短线被资金撤出。

机构 / 消息催化

强验证催化：长鑫科技上市带来硬科技估值重估和流动性虹吸，半导体、存储、PCB、MLCC同步受益。产业催化：脑机接口、AI应用、国产算力、半导体材料设备仍是中期科技主线的一部分，叠加上半年工业企业利润中电子链表现突出的线索，支撑资金回流。政策/基本面催化：创新药、医疗器械、电池链等方向兼具中报业绩和产业政策预期。弱验证部分：部分高压氧舱、机器人、旅游酒店等上涨更多体现为低位轮动，尚不能直接定义为主线。

盘面判断

今天市场交易的是“恐慌出清后的硬科技再定价”。反身性看，长鑫科技的超大成交和夸张涨幅，不只是新股事件，也是在告诉市场：只要有足够强的产业叙事和流动性锚，风险偏好会迅速自我强化。问题是，单日普涨不等于主升确认。当前状态是“情绪修复 + 题材扩散 + 成交放大”，比上周五好很多，但仍需要明天验证承接。如果成交继续维持2万亿以上，科技主线有机会从修复走向进攻；若缩量回落，则容易进入高低切轮动。

明日观察

1）两市成交额能否继续站稳2万亿元上方；2）长鑫科技能否维持高成交而不出现极端负反馈；3）脑机接口、PCB、MLCC能否出现二板扩散，而不是一日游；4）创业板指能否继续强于沪指，确认成长风险偏好延续；5）立新能源、爱丽家居等高标是否温和分歧，若高标集体断板并扩散跌停，短线情绪会快速降温。

复盘总结

7月27日A股从“缩量杀跌”切到“放量修复”，核心变量是长鑫科技上市引爆硬科技风险偏好，随后脑机接口、PCB、MLCC、创新药等题材扩散。机会等级从上周五的低位试错提升到“可观察进攻”，但还不是无脑追涨环境。能博的是有成交、有辨识度、有产业催化的核心，后排纯情绪股一旦明天缩量就容易兑现。市场复盘，不构成投资建议。

港美股复盘｜港股 2026-07-27 / 美股 2026-07-27

宏观背景

港股最近一个已收盘交易日为2026-07-27，美股最近一个已收盘交易夜盘为美东2026-07-27。宏观层面出现边际缓和：油价回落、美国与伊朗冲突暂停相关消息降低了通胀和地缘风险担忧，美债收益率同步回落，有利于风险资产修复。但美股内部仍分化，芯片和科技拖累纳指，说明全球资金还没有进入全面risk-on。港股对美债、美元、人民币和中概科技映射敏感，所以当天反弹更像估值和情绪修复，而不是基本面趋势反转。

指数表现

港股三大指数集体上涨：恒生指数涨0.98%报25207.18点，全日主板成交约2105亿港元；国企指数涨1.14%报8365.38点；恒生科技指数涨1.57%报4702.05点。恒科强于恒指，说明弹性资产重新占优。美股方面，道指收涨约260点，标普500小幅收涨，纳指因芯片和科技权重走弱收跌，罗素和市场广度线索未形成强共振，因此不能定义为全面风险偏好修复。

市场风格

港股风格从上周五的防御高股息，切换为“科技弹性修复 + 题材反弹”。小米、美团、腾讯等权重科技股走强，PCB、AI大模型、黄金、航空、硬件设备等板块活跃；石油石化、半导体、煤炭、电力偏弱。这个结构说明资金在做两件事：一是跟随A股硬科技与消费电子情绪回流；二是对前期调整较深的恒科做估值修复。但南向资金仍净卖出超15亿港元，风格修复与资金流向存在分歧。

板块主线

港股最强主线是“科技弹性 + A股映射”。小米集团受技术发布会预期、汽车/AI硬件叙事以及长鑫科技持股受益线索推动，收涨7.34%，成为恒科反弹核心。PCB概念领涨，芯碁微装涨超19%，建滔积层板、胜宏科技涨超6%，对应A股PCB/硬科技回暖。AI大模型方向MiniMax涨17.14%、智谱涨超3%，体现前期弱势品种的弹性修复。黄金、航空也有表现，但更偏轮动而非主线。

核心个股

港股核心：小米集团-W涨7.34%，美团-W涨3.00%，腾讯控股涨1.93%，阿里巴巴-W涨0.91%，MiniMax-W涨17.14%，智谱涨超3%；PCB链中芯碁微装涨19.33%，建滔积层板、胜宏科技涨超6%。弱势样本：蔚来、小鹏集团下跌，部分石油石化、煤炭、电力股回落。美股核心观察：大型科技内部继续分化，芯片与部分科技股压制纳指，道指相对强，说明资金更偏低波动和盈利确定性。

中概 / 港股映射

映射关系偏强但不纯粹。A股长鑫科技上市和硬科技普涨，对港股小米、PCB、半导体和AI大模型形成直接情绪映射；港股恒科强于恒指，也反向确认成长修复。但美股纳指收跌、芯片科技偏弱，又对港股科技形成外部约束。南向资金净卖出超15亿港元，说明内资并未完全追随价格反弹。结论：这是“强A股映射 + 弱美股映射 + 资金分歧”的修复行情。

消息 / 财报催化

强验证：小米7月30日技术发布会预期、长鑫科技上市对小米持股收益和硬科技情绪的带动、PCB链随A股同步修复。中等验证：AI大模型公司MiniMax受机构交流和商业化预期提振，智谱等跟涨；黄金股受避险与商品价格扰动影响。宏观催化：油价回落和地缘冲突缓和降低美联储通胀压力，但FOMC前资金仍谨慎。未验证部分：港股部分小票急涨更偏情绪修复，尚需成交和业绩确认。

盘面判断

港美股今天交易的是“压力缓和后的弹性修复”，不是全面反转。港股的好处是恒科强于恒指，科技权重和题材都在涨；坏处是南向继续净卖出，美股纳指偏弱，外部科技映射并不配合。反身性看，港股前期压得越低，稍有催化就容易弹得更快，但如果资金没有持续流入，反弹会很快被兑现盘压住。当前状态更接近“港股高弹性反弹 + 美股指数分化”。

下一交易日观察与总结

下一交易日看五个条件：1）美债收益率和美元是否继续回落；2）纳指与芯片股能否止跌，否则恒科弹性会受压；3）港股成交能否维持2000亿港元以上；4）南向资金能否从净卖出转为净流入；5）小米、腾讯、美团、PCB链能否继续承接。总结：港股短线修复成立，但确认进攻还差资金回流；美股道指和标普企稳，纳指仍是短板。市场复盘，不构成投资建议。
